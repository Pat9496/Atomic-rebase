# Security Policy

## Supported Versions

This project does not currently follow a versioned release process; the
`main` branch is the only supported version.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities
(for example: a code path that could lead to privilege escalation, arbitrary
command execution, or unsafe handling of `sudo`).

Instead, report it privately using
[GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
(**Security** tab → **Report a vulnerability**), or by emailing
pat9496@pm.me directly.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- Any relevant `rpm-ostree status`, script version/commit, or environment
  details.

We'll acknowledge reports as soon as possible and work with you on a fix
before any public disclosure.
